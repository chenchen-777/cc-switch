# CC Switch 777

A custom build of [CC Switch](https://github.com/farion1231/cc-switch), based on v4.0.9, commit a98207e2c44d6d99c500e01b058127b1bddf9353. Original author: Jason Young. MIT license retained. This is an independent distribution.

Removes partner promotion copy, sponsored badges and sorting, and referral parameters in provider links. Existing provider configurations and functional presets remain usable. Updates and downloads use this repository only.

Release: v4.0.9-777.1. Application/MSI version: 4.0.7775.

[Download Windows and macOS installers](https://github.com/chenchen-777/cc-switch/releases/latest)

Build: pnpm install --frozen-lockfile; pnpm typecheck; pnpm test:unit; pnpm tauri build. On Windows set CARGO_TARGET_DIR to a build directory under D:\Codex维护工程.
